# Embistic 0.5.0

歌词设置直接出现在需要的位置，调整时保留右侧歌词预览；减少滚动与逐字渲染中的重复布局，并补充播放队列和多个本地列表管理。

- 左侧边栏「歌词」直接进入外观、同步和来源设置。点击播放控制器的专辑封面进入沉浸歌词。
- 主内容区增加返回按钮，从首页打开专辑后可回到原浏览位置；支持 Alt + 左方向键和鼠标侧键。
- 桌面歌词按整个窗口矩形检测悬停，移入显示背景、边框和选项，移出或锁定后仅显示文字；固定工具栏空间，修复悬停时歌词位置跳动。
- 沉浸页面右上角「歌词设置」在左侧封面位置展开，可调整字体、字号、配色、描边、布局、动效、时间偏移和来源；右侧歌词实时预览。
- 歌词外观、频谱和来源设置自动保存，频谱设置也使用左侧面板，关闭面板保留修改。
- 封面展示可选圆形封面、旋转唱片和圆角方形封面。环绕频谱对应封面轮廓，唱片模式下位于整张唱片外圈。
- 上下频谱避开显示中的选项和播放控制器，并随控制器收起移动到窗口边界。
- 改进主窗口圆角外观，保留自绘标题栏、窗口拖动、缩放、最大化和全屏。
- 歌词滚动改为渲染变换，复用逐行文字和逐字高亮缓存，在空闲时预热下一行；减少换行时的全表更新和无效动画。频谱共享帧数据并复用绘制资源，减少多方向显示时的重复工作。
- 播放控制器新增弹出式播放列表，可增删当前队列、拖动或用按钮调整顺序，双击歌曲开始播放。
- 「我的列表」支持保存多个本地列表，可新建、加载、重命名、更新和删除，也可从歌曲或封面右键菜单加入指定列表；列表按服务器和账号分别保存。
- 打开专辑会读取专辑全部曲目放入当前队列，不会自动播放专辑，当前正在播放的歌曲继续播放。

保留 Emby 登录、本机输出设备选择、DLNA、透明桌面歌词、后台托盘播放、音乐下载和自定义缓存目录。

增加沉浸布局、内嵌设置、播放列表、返回导航和桌面歌词专项检查，覆盖真实鼠标悬停、穿透、拖动排序、退出落盘及歌词画面变化。目标帧率可配置，实际流畅度取决于设备、窗口大小和系统负载。

安装版与免安装版均包含 .NET 和 libVLC，可通过 SHA256SUMS.txt 核对发行文件。已有设置和本地缓存可继续使用。
