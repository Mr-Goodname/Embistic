# 自定义网络歌词来源

进入左侧边栏「歌词 → 来源」，添加自己的 HTTP / HTTPS GET 接口。沉浸歌词页面也可点击右上角「歌词设置」，切换到「来源」；设置面板显示在左侧专辑封面位置，右侧歌词继续显示。

来源可以启用、关闭和调整顺序，也可以将配置导出为 JSON 或导入别人分享的接口配置。有效修改会自动保存，没有单独的保存按钮；导入的配置也会自动应用。地址或字段不完整时先根据面板提示修正，避免用无效配置替换已有来源。

手动导入的歌词和 Emby 同步歌词优先。网络匹配先读取对应配置的缓存，再按自定义来源顺序尝试，最后使用内置 LRCLIB 和网易云。修改接口或禁用来源后会使用新的缓存，不会继续显示被替换来源的旧结果。

## 直接获取歌词

「歌词接口地址模板」支持这些占位符，参数会自动 URL 编码：

| 占位符 | 含义 |
| --- | --- |
| `{title}` | 歌曲名称 |
| `{artist}` | 歌手 |
| `{album}` | 专辑 |
| `{duration}` | 秒数，可包含小数 |
| `{durationMs}` | 毫秒数 |
| `{id}` | 搜索结果的歌曲 ID；直接接口中为 Emby 曲目 ID |

例如 LRCLIB 的直接接口：

```text
https://lrclib.net/api/get?track_name={title}&artist_name={artist}&duration={duration}
```

它返回 JSON，歌词字段填 `syncedLyrics`。返回纯歌词文本的接口，歌词字段留空。嵌套 JSON 可用 `data.lyric`，数组字段可用 `items[0].lyric`。

## 搜索后获取歌词

如果接口要求先搜索歌曲，再通过 ID 获取歌词：

1. 填写「搜索 GET 地址模板」，通常包含 `{title}` 和 `{artist}`。
2. 填写结果数组字段，例如 `result.songs`；数组在根节点则留空。
3. 配置 ID、歌名和歌手字段，例如 `id`、`name` 和 `artists[0].name`。
4. 可填写时长字段，并选择秒或毫秒。匹配会检查歌名、歌手和时长，避免抓取错误版本。
5. 在歌词接口模板中使用 `{id}`。

「测试当前歌曲」可以检验选中的接口，并显示获得的歌词片段。未匹配、请求超时或响应字段不正确时，会继续尝试后续来源。

此配置功能用于定义接口，不执行 ESLyric 的 JavaScript 或 Lua 脚本。接口若返回真实逐字时间，播放器会保留这些时间；普通按行歌词不会被编造为逐字歌词。
