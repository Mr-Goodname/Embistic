# Embistic 0.4.0

改进沉浸歌词、桌面歌词和频谱，加入后台播放与可自定义目录的音乐缓存。

- 自绘主窗口标题栏，支持拖动、缩放、最小化、最大化与全屏。
- 歌词页顶部选项和底部播放条自动隐藏，鼠标移到相应区域时显示。
- 频谱使用圆滑曲线，支持上下左右多选及环绕封面，帧率独立于响应平滑度。
- 当前歌词聚焦放大，邻近歌词逐渐缩小；改进滚动动画与逐字歌词显示，支持时间偏移。
- 桌面歌词默认透明，只显示歌词文字；提供已唱/未唱颜色、描边、阴影与独立对齐等外观设置。
- 自定义网络歌词接口，支持文本/JSON、搜索后获取、来源顺序、启用开关和配置导入导出。
- 修复滑块轨道无法连续拖动的问题，并扩大可抓取区域。
- 关闭主窗口时默认隐藏到托盘，继续播放；可关闭此选项。托盘提供播放、暂停、切歌、恢复与退出。
- 可选择音乐下载目录，也可开启播放时自动缓存；已下载音频优先本机播放，切换目录会复制已有下载。

保留账号密码与 API 密钥登录、本机输出设备选择、DLNA、播放队列和媒体库浏览等功能。

安装版与免安装版均包含 .NET 和 libVLC；安装前可通过 SHA256SUMS.txt 核对文件。
